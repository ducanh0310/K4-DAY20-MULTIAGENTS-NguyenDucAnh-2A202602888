---
name: validate-data-output
description: Use this skill to ensure that data outputs conform to specified formats and requirements.
---
- Check that monetary values are represented in integer cents, not as decimal values.
- Ensure that all output files contain the required metadata, including source file name and row counts.
- Validate that CSV files have the correct headers and that each row corresponds to distinct entries.
- Confirm that all region names are standardized and formatted correctly.
- Review the output for any missing or incorrect values, especially in key metrics.
