---
name: log-formatting-and-validation
description: Use this skill to ensure that log entries are formatted and validated according to specifications.
---
- Ensure that the log entries contain the correct number of entries as expected.
- Validate that timestamps are in UTC format and are unique.
- Check that exception fields contain valid values and are not null.
- Confirm that repeat counts are accurately calculated for each error.
- Ensure that service names are formatted in lower-case with underscores instead of hyphens.
- Sort log entries by service name and timestamp in ascending order.
- Verify that the top-level object includes the correct schema version and generated by information.
