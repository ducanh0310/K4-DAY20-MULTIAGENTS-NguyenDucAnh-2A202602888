---
name: validate-test-files
description: Use this skill to ensure that test files are not modified and adhere to the required structure.
---
- Always create new test files instead of modifying existing ones in the tests directory.
- Verify that the test files follow the naming conventions and structure specified in the project documentation.
- Ensure that all test cases are independent and can run in isolation without relying on the state of other tests.
- Check that the test files include appropriate assertions to validate expected outcomes.
- Confirm that the test files are located in the correct directory and are discoverable by the testing framework.
- Review the test files for any syntax errors or issues that may prevent them from executing correctly.
